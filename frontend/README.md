# Tower Defense Frontend

塔防游戏前端。

## 快速开始

```bash
# 来到前端目录
cd frontend

# 安装依赖
npm install

# 创建本地开发环境配置
cp .env.example .env.local

# 开发模式
# 开发服务器默认运行在 http://localhost:8080
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview

# 测试
npm run test
```
